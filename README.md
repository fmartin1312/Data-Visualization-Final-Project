## Final Presentation and Repo

This project explores European flight data from 2016 to 2022, and analyzes and visualizes trends in flight departures across key European countries. The analysis focuses particularly on the impact of Brexit on UK air travel alongside examining the broader effect of COVID-19 on flight volume across Europe.

The repository is organized to clearly separate data, code, and plots. The main Quarto/R Markdown report includes a presentation of my visualizations and analysis. 
Supporting scripts and data files are stored in dedicated folders, described below, to ensure reproducibility and easy navigation.

- [`data/`](data): contains the data sets used for this project
- [`plots/`](plots): contains the graphs included in my presentation
